# MeatyEFT — Escape from Tarkov DMA Radar

Escape from Tarkov için gelişmiş harici DMA radar ve yardımcı araç seti. Performans, temiz görsel ve canlı veri özellikleri odaklı.

## Özellikler

- **DMA Radar** — canlı raid haritası üzerinde oyuncu, loot ve çıkış noktası görselleştirme
- **Harici Yöntem** — oyun PC'sine dokunmaz, DMA kartı üzerinden çalışır
- **Fuser Desteği** — dahili ama zorunlu değil
- **Bellek Yazma Yok** — sadece okuma, firmware güncelliğinde güvenli kabul edilir
- **ImGui Arayüz** — C++ ile yüksek performanslı görselleştirme

## Gereksinimler

- DMA kartı (pcileech uyumlu, güncel firmware)
- İkinci PC
- Windows 10/11

## Yapı

```
MeatyEFTRelease/       — ana proje kaynak kodu
MeatyEFTRelease.slnx   — Visual Studio çözüm dosyası
```

## Derleme

Visual Studio 2022 ile çözümü aç → Release x64 → Build.
